KEBIJAKAN PRIVASI (PRIVACY POLICY)

Ngayomi lan Nglindhungi Data Pamaca Situs PAWARTA

ꦫꦲꦫꦾ ꦱꦠꦸꦩꦸꦤ꧀ ꦏꦂꦪ

Ing PAWARTA (https://pawarta.github.io/), privasi para pamaca minangka prekara sing wigati banget tumrap kamajengan situs web iki. Dokumen Kebijakan Privasi iki nerangake jinis informasi apa wae sing dikumpulake lan dicathet dening PAWARTA sarta kepiye cara kita nggunakake informasi kasebut.

1. Log Files (Cathetan Akses)

Kaya dene akeh situs web liyane, PAWARTA nggunakake file log (log files). Informasi sing ana ing jero file log kalebu alamat protokol internet (IP), jinis browser, Internet Service Provider (ISP), tanggal/wektu, kaca rujukan/keluar, lan jumlah klik. Data iki digunakake kanggo nganalisis tren, ngurus situs web, nglacak gerakan pangguna ing situs web, lan ngumpulake informasi demografi. Alamat IP lan informasi liyane ora disambungake karo data sing bisa diidentifikasi sacara pribadi.

2. Cookies lan Web Beacons

PAWARTA nggunakake cookie kanggo nyimpen informasi babagan preferensi pengunjung, ngrekam informasi khusus pangguna ing kaca sing diakses pengunjung, lan ngatur utawa nyesuaikan konten kaca web adhedhasar jinis browser pengunjung utawa informasi liyane sing dikirimake pengunjung liwat browser kasebut.

3. Kebijakan Google AdSense & Cookie DoubleClick DART

Minangka panyedhiya iklan pihak katelu, Google nggunakake cookie (kalebu cookie DART) kanggo nampilake iklan ing situs web PAWARTA:

  • Google nggunakake cookie DART supaya bisa nampilake iklan marang para pamaca adhedhasar kunjungan marang situs web PAWARTA lan situs web liyane ing internet.
  • Pamaca bisa milih mateni panggunaan cookie DART kanthi ngunjungi Kebijakan Privasi jaringan iklan lan konten Google ing alamat URL: https://policies.google.com/technologies/ads.

Mitra pariwara pihak katelu utawa jaringan iklan uga nggunakake teknologi kayata JavaScript, Cookie, utawa Web Beacons sing digunakake ing iklan lan tautan sing katon ing PAWARTA, sing dikirim langsung menyang browser pangguna. Nalika iki kedadeyan, dheweke otomatis nampa alamat IP panjenengan. Teknologi kasebut digunakake kanggo ngukur efektifitas kampanye pariwara lan/utawa kanggo nersonalisasi konten iklan sing dideleng ing situs web sing panjenengan kunjungi.

4. Kebijakan Privasi Pihak Ketiga

Kebijakan Privasi PAWARTA ora ditrapake kanggo pengiklan utawa situs web liyane. Pramila, kita nyaranake supaya panjenengan maca Kebijakan Privasi sing luwih rinci saka server iklan pihak katelu kasebut kanggo informasi sing luwih lengkap. Bisa uga kalebu praktik lan instruksi babagan cara milih ora kabeh (opt-out) pilihan tartamtu.

5. Persetujuan (Consent)

Kanthi nggunakake situs web PAWARTA, panjenengan kanthi iki setuju karo Kebijakan Privasi lan setuju karo syarat lan Ketentuan (Terms & Conditions) sing wis kasebut.

6. Hubungi Kami

Yen panjenengan duwe pitakonan tambahan utawa mbutuhake informasi luwih lengkap babagan Kebijakan Privasi iki, mangga hubungi liwat kaca Contact Us.
